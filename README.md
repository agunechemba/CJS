# About Coding with JavaScript — A Young Programmer's Journey

This project is an **interactive storybook** designed to introduce children (and curious beginners of any age) to the JavaScript programming language. It is built with plain HTML, CSS, and vanilla JavaScript, and it runs entirely in the browser — no build tools, no dependencies, no server required.

The book is a refactored and illustrated adaptation of *Coding with JavaScript For Dummies* by **Chris Minnick** and **Eva Holland**, rewritten with a gentle, story-driven tone for young readers. All mistakes in the retelling are the adapter's own.

## The Journey in Three Parts

The book is divided into three progressive parts, each aimed at a different age range:

| Part | Title | Age Range | Focus |
|------|-------|-----------|-------|
| One | **Adventurers** | 5–8 | First steps: what JavaScript is, tools, variables, arrays. |
| Two | **Explorers** | 9–11 | Choices, loops, functions, objects, the DOM, events, forms, graphics. |
| Three | **Masters** | 12–13 | Regular expressions, callbacks, closures, AJAX, JSON, BOM, HTML5 APIs, jQuery, debugging. |

Each chapter includes:

- A short **story** that introduces the concept in plain language.
- A **Key Ideas** box summarising the takeaway.
- **Try It Yourself** questions and exercises.
- Illustrated **code examples** with syntax highlighting.

## How to Use the Book

The book is presented as a sequence of pages, like a physical storybook.

- **Turn pages** with the on-screen buttons, or with the **left and right arrow keys**.
- **Jump to any chapter** using the clickable Table of Contents.
- A **reading progress bar** at the top shows how far you've read.
- A **page indicator** in the corner tells you your current page.
- The layout is **responsive** and works on phones, tablets, and desktops.
- If JavaScript is disabled, all pages stack into a single scrollable document so the content remains accessible.
- Reduced-motion preferences are respected.

## Files

The project consists of three files:

- `index.html` — the book content and structure.
- `styles.css` — the storybook styling and responsive layout.
- `script.js` — the page-navigation engine.

To run it, simply open `index.html` in any modern browser.

## A Note for Grown-Ups

This book is meant to be read together. Encourage the young programmer to type the examples into a browser console, break them, fix them, and make them their own. Every programmer, every day, writes mistakes — that is how we learn.
